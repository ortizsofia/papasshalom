## Descripción del Videojuego

PapasShalom es un videojuego de simulación inspirado en Penguin Diner y Papers, Please.

El jugador controla a una camarera encargada de atender un restaurante. Deberá recibir clientes, asignar mesas, tomar pedidos, servir comida y bebidas, cobrar y limpiar las mesas.

Al finalizar cada nivel, el jugador administrará el dinero obtenido para cubrir gastos personales como renta, alimentación y calefacción. Sus decisiones tendrán consecuencias sobre la calidad de vida del personaje.

## Tecnologías Principales

- Java

- LibGDX

- Gradle

Plataformas objetivo:

- Desktop (LWJGL3)


## Compilación y Ejecución

1. Clonar el repositorio.

2. Abrir el proyecto en IntelliJ IDEA.

3. Esperar la sincronización de Gradle.

4. Ejecutar la clase Lwjgl3Launcher del módulo lwjgl3.
